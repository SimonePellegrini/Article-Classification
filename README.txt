The final pipeline is contained in the main.py file. 
To execute the pipeline, the library Beautiful Soup is necessary. 
To install it, just use the following command:

- pip install beautifulsoup4

All the preliminary studies, including plots and grid searches, can be found in the notebook called "file.ipynb".
To replicate the results obtained in the submission.csv, it is sufficient to run the main.py file.

"finalPyNotebook.pdf" is a PDF version of final.ipynb, included as a backup in case of execution errors.
